# 📊 Analysis of Psychological Factors Affecting Teacher Burnout  
### Using SEM and CFA Approaches

This project is a **quantitative data analysis study** that examines psychological factors influencing **teacher burnout** using **Structural Equation Modeling (SEM)** and **Confirmatory Factor Analysis (CFA)**.

The study focuses on how **Teacher Self-Concept (TSC)** and **Teacher Efficacy (TE)** affect three dimensions of burnout: **Emotional Exhaustion (EE)**, **Depersonalization (DE)**, and **Reduced Personal Accomplishment (RPA)**.

---

## 🎯 Research Objectives
- Identify key psychological factors influencing teacher burnout  
- Analyze the structural relationships between TSC, TE, and burnout dimensions  
- Validate measurement constructs using CFA  
- Test a theory-driven structural model using CB-SEM  

---

## 📂 Dataset
- Source: *Habibi et al. (2020), Mendeley Data*  
- Respondents: **250 teachers** from Southeast Asia (primarily Indonesia)  
- Data type: Likert-scale survey (numeric, structured)  

---

## 🧠 Variables
**Exogenous Variables**
- Teacher Self-Concept (TSC)
- Teacher Efficacy (TE)

**Endogenous Variables (Burnout Dimensions)**
- Emotional Exhaustion (EE)
- Depersonalization (DE)
- Reduced Personal Accomplishment (RPA)

---

## 🛠️ Methodology
- Data preprocessing and exploratory data analysis (EDA)  
- Assumption testing (normality & multicollinearity)  
- Confirmatory Factor Analysis (CFA)  
- Structural Equation Modeling (SEM) using **Maximum Likelihood Robust (MLR)**  
- Model evaluation using fit indices (CFI, TLI, RMSEA, SRMR)  

---

## 📈 Key Results
- All constructs demonstrated **good validity and reliability**  
  (Cronbach’s Alpha > 0.70)  
- The SEM model showed **good model fit**  
  - CFI ≈ 0.94  
  - TLI ≈ 0.93  
  - RMSEA ≈ 0.055  
  - SRMR ≈ 0.039  
- Teacher Self-Concept and Teacher Efficacy significantly influenced all burnout dimensions  

---

## 🧩 Conclusion
The findings indicate that **psychological factors play a significant role in teacher burnout**. Strengthening teachers’ self-concept and teaching efficacy may help reduce burnout levels, particularly emotional exhaustion and reduced personal accomplishment.

This project demonstrates the application of **advanced statistical modeling** for social science and education research.
